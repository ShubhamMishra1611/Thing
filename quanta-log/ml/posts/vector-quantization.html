Vector Quantization

Codebooks, residuals, and why discrete latent spaces are having a moment.

Dec 5, 2025 · 9 min read

I recently came across this paper and decided to revisit some foundational concepts before diving in.

Vector quantization (VQ) is a technique from signal processing and machine learning that compresses high-dimensional data by mapping vectors to a finite set of representative points called codewords. It's essentially a way to approximate many data points using a smaller set of prototypes.

VQ matters today because modern generative models desperately need discrete, compact, and stable latent representations. VQ gives you exactly that: tight compression for audio/video codecs, clean tokenization for image/audio transformers.

What Vector Quantization Does

It takes a vector (e.g., a block of audio samples, an image patch, or an embedding) and replaces it with the nearest entry in a codebook.

  • Input: continuous vector
  • Output: discrete index of the nearest codeword

This reduces storage and provides regularization in machine learning.

Important Components

1. Codebook

A set of $K$ representative vectors (codewords). The codebook can be learned using:

  • k-means clustering (classic VQ)
  • Neural network training (e.g., VQ-VAE, RVQ)

2. Encoder

Maps the input vector to the nearest codeword: $\hat{z} = \arg\min_{c_k \in \mathcal{C}} \|z - c_k\|_2$

3. Decoder

Reconstructs the input by looking up that codeword index.

Bitrate vs Distortion

Lower bitrate means fewer codewords, which increases distortion because more vectors get forced into the same prototype. Higher bitrate gives finer codebooks and lower reconstruction error, but at the cost of more storage and more bits per token. VQ, RVQ, and QTIP all exist to push distortion down without letting bitrate explode.

Scalar and Vector Quantization

Scalar quantization is the simpler approach — it quantizes each value independently. Vector quantization quantizes whole vectors, capturing correlations between dimensions.

Residual Vector Quantization

Instead of using one codebook to quantize a vector, RVQ uses multiple codebooks sequentially:

  1. Quantize the input with codebook $C_1$
  2. Calculate the residual (error)
  3. Quantize the residual with codebook $C_2$
  4. Repeat for $M$ stages

The final representation is the sum of all quantized components:

$$\hat{x} = q_1 + q_2 + \cdots + q_M$$

Here's how the 3-stage RVQ walkthrough looks in code:

import numpy as np

# Our example vector
x = np.array([10.5, 8.3])

# Define codebooks (pre-trained for this example)
C1 = np.array([[10, 8], [2, 3]])
C2 = np.array([[0.4, 0.4], [-0.3, -0.2]])
C3 = np.array([[0.1, -0.1], [-0.05, 0.05]])

codebooks = [C1, C2, C3]
indices = []
reconstruction = np.zeros_like(x)
residual = x.copy()

for stage, C in enumerate(codebooks, 1):
    distances = [np.linalg.norm(residual - c) for c in C]
    idx = np.argmin(distances)
    q = C[idx]
    reconstruction += q
    residual = residual - q
    indices.append(idx)
    print(f"Stage {stage}: idx={idx}, q={q}, residual={residual}")

print(f"\nOriginal:       {x}")
print(f"Reconstructed:  {reconstruction}")
print(f"Stored indices: {indices}")
print(f"Final error:    {np.linalg.norm(residual):.6f}")

Learned Vector Quantization

LVQ builds a minimal set of representative class-prototypes and uses them like a compressed nearest-centroid classifier — but learns the prototypes via supervised updates, not clustering.

You maintain a small set of prototype vectors, each associated with a class. For a new data point, you find the closest prototype and classify it as that prototype's class. During training, prototypes shift:

Training loop:

  1. Find the closest prototype (by Euclidean distance). This is the "winner."
  2. Check if the winner has the same class as the example.
    • If correct class: move the prototype a little closer to the example.
    • If wrong class: move the prototype a little farther away.
  3. Repeat for many epochs.
import numpy as np

class LVQ:
    def __init__(self, prototypes, proto_labels, lr=0.1):
        self.w = prototypes.copy()
        self.labels = np.array(proto_labels)
        self.lr = lr

    def _winner(self, x):
        dists = np.linalg.norm(self.w - x, axis=1)
        return np.argmin(dists)

    def train(self, X, y, epochs=10):
        for ep in range(epochs):
            for xi, yi in zip(X, y):
                j = self._winner(xi)
                if self.labels[j] == yi:
                    self.w[j] += self.lr * (xi - self.w[j])
                else:
                    self.w[j] -= self.lr * (xi - self.w[j])

    def predict(self, X):
        return np.array([self.labels[self._winner(xi)] for xi in X])


# --- Example usage ---
X = np.array([[0,0],[0,1],[1,0],[1,1],[5,5],[5,6],[6,5],[6,6]], dtype=float)
y = np.array([0,0,0,0, 1,1,1,1])

prototypes  = np.array([[0,0],[5,5]], dtype=float)
proto_labels = [0, 1]

lvq = LVQ(prototypes, proto_labels, lr=0.2)
lvq.train(X, y, epochs=20)

test = np.array([[0.2,0.1],[5.5,5.2],[1,1],[4,4]])
print("Predictions:     ", lvq.predict(test))
print("Final prototypes:", lvq.w)

VQ-VAE

A VQ-VAE is a neural autoencoder that uses vector quantization to map continuous latent vectors into a discrete codebook for stable and efficient generative modeling. That rabbit hole deserves its own post — covering variational autoencoders first would help build the right intuition.

This foundational understanding is what you need before diving into recent work like QTIP, which pushes the bitrate-distortion frontier further using trellis-coded quantization.
