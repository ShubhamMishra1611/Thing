Model Souping

Jun 21 2024 · 8 min read · Shubham

Model souping is like a secret ingredient that improves the accuracy and robustness of fine-tuned models without adding any extra weight to inference time. This is done by averaging the weights of multiple models trained with diverse hyperparameter configurations.

Imagine this: instead of juggling multiple models during inference (which, let's be honest, sounds like a logistical nightmare), we simply combine their weights. Voila! We get a single, souped-up model that's more accurate than any individual one.

Why is Model Souping Effective?

Here's the magic: even when we fine-tune models with different hyperparameters, they often settle into a cozy low-error basin in the loss landscape.

This means that averaging their weights can produce a solution that performs better than any individual model.

To break it down:

  • Interpolating the weights of two fine-tuned models can result in a solution with higher accuracy than either of the original models.
  • Models trained with varied hyperparameters bring uncorrelated solutions to the table. Mixing these uncorrelated solutions leads to even greater accuracy improvements.

How Does Model Souping Save Inference Time?

Model souping differs from traditional ensembling methods in a crucial way: it combines model weights during training rather than model outputs during inference.

Ensembles: Traditional ensembles require separate inference passes through each model, increasing computational cost linearly with the number of models. This becomes prohibitively expensive when dealing with many models.

Model Soups: Model soups create a single model by averaging weights. It's like the chefs pooled their best ideas into one perfect dish. By averaging weights during training, we end up with one model, with no extra inference time needed.

Model Souping Recipes

First, let us have some mathematical formalities:

A model is represented as $f(x, \theta)$ with input as $x$ and parameters as $\theta$. Fine-tuned parameters can be represented as $\theta = \text{FineTune}(\theta_o, h)$, where $\theta_o$ is the parameters you get from pretraining, and $h$ is the hyperparameter configuration. So $\theta_i$ is the parameter we got for $h_i$ hyperparameter configuration.

Now, let's dive into some "recipes" for model souping:

Uniform Soup

This one's simple — just average the weights of all fine-tuned models equally. But beware, if some models are duds, they can drag down the overall performance. So mathematically,

$$\theta_{\text{soup}} = \frac{1}{k}\sum_{i=1}^{k}\theta_i \quad \Rightarrow \quad O(1) \text{ inference}$$

Here, $O(1)$ refers to constant time inference.

Greedy Soup

Sequentially adds models to the soup, only keeping those that improve accuracy on a held-out validation set. This method is like a picky eater — it only adds models that improve accuracy on a validation set. The result? A soup that's always better than the best individual model.

It would look more like the following:

for model in sorted_models:
        if greedy_soup is None:
            new_soup = model
        else:
            new_soup = average_weights([greedy_soup, model])

        new_accuracy = evaluate_model(new_soup, testloader)

        if new_accuracy > best_accuracy:
            best_accuracy = new_accuracy
            greedy_soup = new_soup

Learned Soup

It involves learning the soup mixing coefficients for each of the ingredient. While potentially more accurate, this method requires loading all models in memory simultaneously, limiting its use with large networks. For a given loss $l$ and pair $(x, y)$, we can find mixing coefficient $\alpha$ and temperature scaling parameter $\beta$, following is a equation to scare you out:

$$\min_{\alpha, \beta} \; \mathbb{E}_{(x,y)} \left[ l\!\left( \text{softmax}\!\left(\beta \cdot f\!\left(x,\; \sum_i \alpha_i \theta_i\right)\right),\; y \right) \right]$$

Let's Implement this because why not, let's get cooking with some code, starting with a simple DNN,

class SimpleDNN(nn.Module):
    def __init__(self, input_size=784, hidden_size=128, num_classes=10, dropout_rate=0.5):
        super(SimpleDNN, self).__init__()
        self.fc1 = nn.Linear(input_size, hidden_size)
        self.dropout = nn.Dropout(dropout_rate)
        self.fc2 = nn.Linear(hidden_size, num_classes)

    def forward(self, x):
        x = x.view(-1, 28*28)
        x = torch.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        return x

Next is training and evaluation:

def train_model(model, trainloader, criterion, optimizer, num_epochs=5):
    model.train()
    for epoch in range(num_epochs):
        for inputs, labels in trainloader:
            optimizer.zero_grad()
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()

def evaluate_model(model, testloader):
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for inputs, labels in testloader:
            outputs = model(inputs)
            _, predicted = torch.max(outputs.data, 1)
            total += labels.size(0)
            correct += (predicted == labels).sum().item()

    accuracy = correct / total
    return accuracy

Now to implement our average souping, we need to load the state_dict and just take average:

def get_model_weights(model):
    return {name: param.data.clone() for name, param in model.named_parameters()}

def set_model_weights(model, state_dict):
    model.load_state_dict(state_dict)

def mean_model_weights(models):
    num_models = len(models)

    total_weights = {name: torch.zeros_like(param.data) for name, param in models[0].named_parameters()}
    for model in models:
        model_weights = get_model_weights(model)
        for name, param in model_weights.items():
            total_weights[name] += param

    mean_weights = {name: param / num_models for name, param in total_weights.items()}

    return mean_weights

For the greedy soup we will be needing average weight module:

def greedy_soup(models, val_accuracies, testloader):
    sorted_indices = np.argsort(val_accuracies)[::-1]
    sorted_models = [models[i] for i in sorted_indices]
    best_accuracy = -np.inf
    greedy_soup = None

    for model in sorted_models:
        if greedy_soup is None:
            new_soup = model
        else:
            new_soup = SimpleDNN(dropout_rate=dropout_rates[0])
            mean_weights = mean_model_weights([greedy_soup, model])
            set_model_weights(new_soup, mean_weights)

        new_accuracy = evaluate_model(new_soup, testloader)

        if new_accuracy > best_accuracy:
            best_accuracy = new_accuracy
            greedy_soup = new_soup

    return greedy_soup

# Calculate the initial val_accuracies before calling greedy_soup
val_accuracies = [evaluate_model(model, testloader) for model in models]

# Call the greedy_soup function
greedy_soup_model = greedy_soup(models, val_accuracies, testloader)
greedy_soup_accuracy = evaluate_model(greedy_soup_model, testloader)
print(f'Greedy Soup Accuracy: {greedy_soup_accuracy}')
