Introduction to Weakly Supervision Learning: Part 1

May 29 2024 10 min read Shubham Mishra

We already have Supervised Learning

Supervised learning is a fundamental paradigm in machine learning where we train models to make predictions based on labeled data. This approach provides the model with input-output pairs (features and corresponding labels) during training. The goal is for the model to learn a mapping from inputs to outputs, allowing it to generalize well to unseen examples.

Key characteristics of supervised learning include:
Labeled Data: Supervised learning relies on having access to a dataset where each example is associated with a known label. For instance, in image classification, each image is labeled with a specific class (e.g., "cat" or "dog").
Predictive Modelling: The model learns patterns from the labeled data and uses them to predict labels for new, unseen data points. Standard algorithms include decision trees, neural networks, and linear regression.
Loss Function Optimization: During training, the model minimizes a loss function (such as mean squared error or cross-entropy) to improve its predictions.

While supervised learning has been successful in various applications (such as image recognition, natural language processing, and recommendation systems), it has some limitations; one of them is :

Data Annotation Costs

Data annotation can be costly because it relies on human workers to ensure accuracy and quality, especially for complex tasks that need detailed understanding. This process is time-consuming and expensive, as it usually involves manually labeling large datasets. High-quality annotation is essential for training effective AI models, which increases the overall cost. The quality of the labels greatly affects model performance; incorrect or biased labels can lead to poor results.

Let's delve into this scenario where we face challenges with supervised learning due to limited data, high annotation costs, or noisy labels. In such situations, weakly supervised learning emerges as a valuable alternative.

Weakly Supervised Learning: A Solution Beyond Traditional Supervision

Weakly supervision serves in the scenario where we have limited or noisy supervision. As has been described on Wikipedia, I will just brief it out:
Weakly supervised learning is a machine learning paradigm designed to efficiently leverage a combination of small amounts of high-quality labeled data and large quantities of unlabeled or imprecisely labeled data.

Now, our weak supervision has three types:
1. Incomplete supervision
2. Inexact supervision
3. Inaccurate supervision

Before delving any deeper, let's formally define a supervised learning task as learning a $f: X \to Y$, where from a training data set
$D = \{(x_1, y_1), \dots, (x_m, y_m)\}$,
where $X$ is the feature space,
$Y = \{Y, N\}$, $x_i \in X$, and $y_i \in Y$.

We assume that $(x_i, y_i)$ are generated according to an identical and independent distribution $\mathcal{D}$.
So what is identical and independent distribution?
"Indentical distributed" means the variables follow the same probability distribution.
"Independently distributed" implies that the generation of any pair $(x_i, y_i)$ does not influence the generation of another pair $(x_j, y_j)$. In essence, all pairs are assumed to be statistical replicas of each other, and the generation of one pair has no effect on the generation of another.

Incomplete Supervision

"Incomplete Supervision" is a scenario where only a part of the training data has labels, while mostly unlabeled data is available. The two main techniques for handling incomplete supervision are active learning and semi-supervised learning. Formally the task in incomplete supervision is defined as learning $f: X \to Y$, where from a training data set
$D = \{(x_1, y_1), \dots, (x_l, y_l), x_{l+1}, \dots, x_m\}$,
where $l$ is the number of labeled training examples (we have $y_i$ for them), and $u = m - l$ is the number of unlabeled instances.

Active Learning: Active learning involves querying an "oracle" (like a human expert) for labels. The goal is to minimize the number of queries to the oracle to train an effective model. So, the idea is to query the label that can provide the most benefit from more information, deliberately querying for the data point that is most uncertain about itself.

Meanwhile, semi-supervised learning uses unlabeled data to improve learning, trying to make use of this data automatically without needing human help.

Note next information is not directly useful for development so you can skip to next section. But still I believe in having complete idea. Unlabeled data must have some connection to the underlying data distribution in order to be used in any way. The following assumptions are used by semi-supervised learning algorithms:
Continuity/ smoothness assumption: Points that are close to each other are more likely to share a label.
Cluster assumption: The data tend to form discrete clusters, and points in the same cluster are more likely to share a label.
Manifold assumption: The data lie approximately on a manifold of much lower dimension than the input space. In this case, learning the manifold using both the labeled and unlabeled data can avoid the curse of dimensionality. Then, learning can proceed using distances and densities defined on the manifold.

Now, let's talk a little more about active learning. Given a small set of labeled data and abundant unlabeled data, active learning attempts to select the most valuable unlabeled instance to query.

Selection criteria

There are two widely used selection criteria:
1. Informativeness: Given a model, it measures how well getting the information about unlabeled data will reduce its uncertainty. The idea is to select instances that provide the most new information to improve the model's predictions on unseen data. Two approaches based on informativeness are mentioned:
a. Uncertainty sampling — This trains a single learner and queries the unlabeled instances on which the learner has the least confidence.
b. Query-by-committee — This generates multiple learners and queries the unlabeled instances on which the learners disagree the most.

2. Representativeness: It measures how well an instance represents the overall distribution or structure of the input patterns in the unlabeled data. The goal is to select representative instances from different clusters or regions of the input space. We can measure representativeness by using clustering method, density-based methods or diversity based method

Other query strategies include Random sampling, Variance reduction, etc.

Workflow of active learning (Image taken from modAL)

An active learning step as demonstrated in the flowchart, it can be explained like this:

  1. Get an initial model: Train it on available labeled data with the initial model.
  2. Train the model on the available labeled data.
  3. Now, predict the unlabeled data with the trained model and get its score, which can be model confidence, entropy, or variance.
  4. Depending upon your query algorithm and what you are measuring, uncertainty is getting the unlabeled data.
  5. Now, ask the oracle (any organization or human annotator) to provide ground truth for your chosen label.
  6. Add this new information (newly annotated data) to the training set, retrain the model, and repeat this until you are exhausted; I mean, the performance threshold has been reached, or the budget is over.

We will now try to train a simple logistic regression model with three approaches: one without active learning, active learning using entropy sampling, and another using a query by committee.

Let's start with importing relevant libraries

import numpy as np
import pandas as pd
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score
from sklearn.model_selection import train_test_split
from tqdm import tqdm

Now, let's define a split function

The provided split function takes a dataset (assumed to have features and labels), splits it into training and testing subsets, and creates an unlabeled set. First, it separates the features (x) and labels (y). Then, train_test_split, it allocates a portion of the data for training (x_train, y_train) while preserving class distributions. The remaining data is split into a test set (x_test, y_test) and an unlabeled set (x_unlabel, y_unlabel). 

def split(dataset, train_size, test_size):
    x = dataset[:, :-1]
    y = dataset[:, -1]
    x_train, x_temp, y_train, y_temp = train_test_split(x, y, train_size=train_size, stratify=y)
    test_size_adjusted = test_size / (1 - train_size)
    x_test, x_unlabel, y_test, y_unlabel = train_test_split(x_temp, y_temp, test_size=test_size_adjusted, stratify=y_temp)
    return x_train, y_train, x_test, y_test, x_unlabel, y_unlabel

Defining data and preprocessing:

dataset =  pd.read_csv(
        "https://archive.ics.uci.edu/ml/machine-learning-databases/spambase/spambase.data").values[:, ]

# Imputing missing data
imputer = SimpleImputer(missing_values=0, strategy="mean")
imputer = imputer.fit(dataset[:, :-1])
dataset[:, :-1] = imputer.transform(dataset[:, :-1])

# Feature scaling
sc = StandardScaler()
dataset[:, :-1] = sc.fit_transform(dataset[:, :-1])

# Arrays to store accuracy of different models
ac1, ac2, ac3 = [], [], []

Now, the first train model uses entropy sampling, where the entropy formula is used on each sample, and the sample with the highest entropy is considered to be the least certain. 

# train model by active learning using entropy sampling
print("Training and evaluating active learning model using entropy sampling")
for _ in tqdm(range(200)):
    x_train, y_train, x_test, y_test, unlabel, label = split(dataset, 0.05, 0.25)
    for _ in range(10):
        classifier1 = LogisticRegression()
        classifier1.fit(x_train, y_train)
        y_probab = classifier1.predict_proba(unlabel)

        # Avoid log(0) by replacing 0 with a small value
        epsilon = 1e-10
        y_probab = np.clip(y_probab, epsilon, 1 - epsilon)
        entropies = -np.sum(y_probab * np.log(y_probab), axis=1)
        highest_entropy_idx = np.argmax(entropies)

        x_train = np.append(unlabel[highest_entropy_idx:highest_entropy_idx+1, :], x_train, axis=0)
        y_train = np.append(label[highest_entropy_idx:highest_entropy_idx+1], y_train)
        unlabel = np.delete(unlabel, highest_entropy_idx, axis=0)
        label = np.delete(label, highest_entropy_idx)
    classifier2 = LogisticRegression()
    classifier2.fit(x_train, y_train)
    ac1.append(classifier2.score(x_test, y_test))

Good, now let's move to the simple model training without active learning involved:

Now for the last one: query by committee where a variety of models are trained on the current labeled data, and vote on the output for unlabeled data; label those points for which the "committee" disagrees the most. So, we will first make a function so that we can get the data points for which learners disagree the most. 

# Function to calculate disagreement among committee members
def calculate_disagreement(probas):
    # Convert probabilities to predicted class labels
    predictions = [np.argmax(proba, axis=1) for proba in probas]
    # Transpose to get predictions for each sample across all committee members
    predictions = np.array(predictions).T
    # Calculate the disagreement (variance) for each sample
    disagreement = np.var(predictions, axis=1)

probas1 = ...  # Predictions from learner 1
probas2 = ...  # Predictions from learner 2
probas3 = ...  # Predictions from learner 3
disagreement_scores = calculate_disagreement([probas1, probas2, probas3])

In this function, probas is a list of predicted probabilities from different learners. The function calculates the variance (disagreement) for each sample based on the class labels predicted by the learners. 

# train with query by committee
print("Training and evaluating active learning model using Query by Committee")
for _ in tqdm(range(200)):
    x_train, y_train, x_test, y_test, unlabel, label = split(dataset, 0.05, 0.25)

    # Train model by active learning using Query by Committee
    for _ in range(10):
        # Train multiple models (committee)
        classifier1 = LogisticRegression()
        classifier2 = RandomForestClassifier()
        classifier3 = GradientBoostingClassifier()

        classifier1.fit(x_train, y_train)
        classifier2.fit(x_train, y_train)
        classifier3.fit(x_train, y_train)

        # Get predictions from each committee member
        probas1 = classifier1.predict_proba(unlabel)
        probas2 = classifier2.predict_proba(unlabel)
        probas3 = classifier3.predict_proba(unlabel)

        # Calculate disagreement
        disagreement = calculate_disagreement([probas1, probas2, probas3])
        most_disagree_idx = np.argmax(disagreement)

        # Add the most disagreeing sample to the training set
        x_train = np.append(unlabel[most_disagree_idx:most_disagree_idx+1, :], x_train, axis=0)
        y_train = np.append(label[most_disagree_idx:most_disagree_idx+1], y_train)
        unlabel = np.delete(unlabel, most_disagree_idx, axis=0)
        label = np.delete(label, most_disagree_idx)

    # Train the final classifier on the expanded training set
    final_classifier = LogisticRegression()
    final_classifier.fit(x_train, y_train)
    ac3.append(final_classifier.score(x_test, y_test))
