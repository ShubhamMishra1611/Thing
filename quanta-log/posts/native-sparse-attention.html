Native Sparse Attention — Hardware-Efficient Sparsity

Feb 22 2026 5 min read Shubham Mishra

Standard Attention

Full self-attention computes a weighted sum of values for every query against every key. Given query matrix $Q$, key matrix $K$, and value matrix $V$, each of shape $(N, d)$:

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d}}\right)V$$

The cost is $O(N^2 d)$ in compute and $O(N^2)$ in memory for the attention matrix. At sequence lengths of 128k tokens this becomes the dominant bottleneck — not the FFN layers.

What NSA Changes

Native Sparse Attention (NSA) proposes three complementary sparse patterns that are hardware-native: they map to contiguous memory access and avoid the scatter/gather overhead that plagued earlier sparse kernels.

1. Blockwise token selection

Rather than selecting individual tokens, NSA selects blocks of $B$ consecutive tokens. A small scoring network picks the top-$k$ blocks per query, reducing the effective context to $k \cdot B$ tokens while keeping memory access patterns sequential. 

import torch
import torch.nn.functional as F

def blockwise_scores(q: torch.Tensor, k: torch.Tensor, block_size: int = 64):
    """
    q: (batch, heads, seq, d_head)
    k: (batch, heads, seq, d_head)
    Returns per-block importance scores.
    """
    B, H, N, D = q.shape
    assert N % block_size == 0
    num_blocks = N // block_size

    # Pool keys within each block
    k_blocks = k.view(B, H, num_blocks, block_size, D).mean(dim=3)  # (B,H,nb,D)

    # Score each block for each query position
    scores = torch.einsum('bhnd,bhmd->bhnm', q, k_blocks)  # (B,H,N,nb)
    return scores / (D ** 0.5)

2. NSA gate mechanism

Each attention head learns a gate $g \in \{0,1\}^{N}$ (relaxed to sigmoid during training) that suppresses non-selected blocks. The gate is conditioned on a compressed representation of the full context so it can make globally-aware selections. 

class NSAGate(torch.nn.Module):
    def __init__(self, d_model: int, num_blocks: int):
        super().__init__()
        # Compress full context to fixed size
        self.pool = torch.nn.AdaptiveAvgPool1d(num_blocks)
        self.proj = torch.nn.Linear(d_model, num_blocks)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: (batch, seq, d_model)
        Returns gate logits: (batch, num_blocks)
        """
        pooled = self.pool(x.transpose(1, 2)).transpose(1, 2)  # (B, nb, d)
        return self.proj(pooled.mean(dim=1))                    # (B, nb)

Complexity comparison

Standard attention vs NSA (selecting $k$ blocks of size $B$ from sequence length $N$):

  • Standard: $O(N^2)$ — every query attends to every key
  • NSA: $O(N \cdot k \cdot B)$ — each query attends to $k$ blocks only

With $k = 16$, $B = 64$, $N = 131072$: standard requires ~$1.7 \times 10^{10}$ ops per head; NSA requires ~$1.3 \times 10^8$ — roughly a 128× reduction.

The key insight is that most attention mass is concentrated in a small fraction of the context. NSA exploits this statistically without paying the hardware penalty of unstructured sparsity.

Current limitations

The block selection itself adds overhead. For short sequences the crossover point where NSA beats flash attention is around 8k tokens. The gating network also needs to be warm — early training steps can see degraded quality until the gate learns meaningful patterns.
